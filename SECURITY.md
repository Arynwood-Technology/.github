# Security policy

This policy covers every Arynwood Technology repository that doesn't have its own SECURITY.md.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. Please don't open a public issue, or
post exploit details or secrets anywhere public.

Include the version or commit you used, how you run it, what an attacker can do and what they
need first, and steps to reproduce.

Reports are acknowledged within **7 days**. Fixes go into the latest release, or the latest
commit on `main` where a repository has no releases. There is no bug bounty program.
